ExpenseManager
me any my friends who live in  a shared pg we use this everyday , we dont like to split the amount while paying bills everytime so we add the expense here and it automatically sets in backend and we can see who wil gonna pay next

A simple full-stack expense-sharing app for tracking shared expenses between friends and calculating who owes whom.

Features
Create users
Add friends
Send and accept friend requests
Add shared expenses
Select who paid
Select who owes the expense
Automatically calculate balances
View expense history
PostgreSQL database with Prisma 8
React + TypeScript frontend
Express + TypeScript backend
